## Project layout

- Keep `AGENTS.md`, `spec.md`, `prompts.md`, and the single-file web app `index.html` at the project root. GitHub Pages serves the root `index.html`.
- Put planning notes and sketches in `00_planning/`.
- Put hand calculations and test cases in `02_validation/`.
- Put screenshots and exported results in `03_output/`.
- Save new files in the folder that matches their purpose; do not add application files or split the web app into other files unless requested.
- After each request, add an entry to `prompts.md` describing what was asked, what changed, and whether it worked.
